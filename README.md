# 🎮 AI PACMAN — 漫画风格 AI 全能客户端

> 集对话、绘画、AI会议室于一体的客户端，漫画风格UI，支持OpenAI兼容API。

## ✨ 功能特性

| 模块 | 功能 |
|------|------|
| 💬 对话 | 多轮上下文、温度/长度调节、流式输出 |
| 🎨 绘画 | 文生图、提示词广场、参考图、15+尺寸 |
| 👥 会议室 | 多角色AI研讨、自定义角色/模型/头像 |
| 🎭 主题 | 漫画/柔和/波点三主题一键切换 |
| 🔒 安全 | 关闭页面自动清除敏感数据 |
